# Fullstack Credit Card UI 💳

A high-performance credit card component with real-time validation and 3D hologram effects.

## Features

- **3D Tilt Effect**: Interactive hologram shine and tilt based on mouse position.
- **Real-time Validation**: Card type detection (Visa, Mastercard, etc.) and number formatting.
- **FastAPI Backend**: Securely handles card data using a Python-based API.
- **SQLite Integration**: Persistent storage for card records.

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Lucide React
- **Backend**: Python, FastAPI, SQLite
